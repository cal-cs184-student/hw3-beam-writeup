Part 1: Ray Generation and Scene Intersection

Primitive Ray Generation

For each pixel, i take ns_aa number of samples. I add a random offset while it's still a grid pixel using get_sample, and then normalize it to 1 x 1 screen, then I remap it to the [-1,1] grid and scale by tan(hFov/2) and tan(vFov/2). I call ray generation to get the outgoing ray, and then gathering it's data using the stub est_radiance_global_illumination and averaging the samples.

Sphere Intersection

Using the fact that p (point of intersection) - c (center of sphere) is the radius definition of radius, we set up function (p-c)^2 - r^2 = 0, which could be turned into (o+td-c)^2 - r^2 = 0, and then turn that into a quadratic equation. if the determentant is less than zero then there is no t intersections. You grab the first one and check if it's within the range, check the second one, and if none of those are in range then its a miss.

Triangle Algorithm

We get the vectors describing the triangle as well as the origin and the direction for the ray. We use the Moller Trumbore to calculate t (the location from the ray), and 2 of the 3 barycentric coordinates. Using the coordinates, we can calculate if the coordinates are all above 0, which means it is inside the triangle.

Part 2: Bounding Volume Hierarchy

BVH Construction

I first compute the bounding box of the primitives and create a node. I then split the boxes into the axis with the highest max - min I chose this because it was a cheap proxy for “items that could be far apart”, which could reduce the size of the bounding boxes, split across the middle using (max - min)/2, and then sorted by calculating a midpoint and sorting the data on that axis, and finally calculating the midpoint as the index to split on and splitting on that index.

Part 3: Direct Illumination

Hemisphere Sampling

I pick a random sample with hemisphereSampler->get_sample(), and turn that into a ray. I use that ray to find the first surface the ray hits at the ray and get the emission if it exists. I also evaluate the BSDF of the surface at hit_p, which tells me how much light arriving from the sampled direction gets reflected toward the camera. I plug that into the monte carlo estimator L_i = emission at ray intersection point, f_r = BSDF at hit_p, and cos is simplified to w_j.z and the bottom probability 1/2pi is moved up because multiplication is cheaper.

Direct Light Sampling

For each light, i picked random samples from the light with light->sample_L. I picked only 1 sample if it was a point light, since multiple would be redundant. Otherwise, it would be ns_area_light. Each sample_L call gives the light arriving at hit_p, a direction, as well as the probability of being picked. Afterwards, you generate the ray and make sure it's not behind a surface, and a shadow ray that makes sure there's nothing blocking the light ray. If none of those conditions are met, then you plug it into the monte carlo algorithm with f*L_I*cos(theta)/pdf.

Part 4: Global Illumination

Indirect Lighting

Indirect lighting is computed by a recursive call that sets the output to the output of one_bounce_radiance if it's the last indirect ray, and optionally adds direct light to every recursive call if the flag is set. It then runs a russian roulette to kill some rays to save on compute except the first one. If it survives, a random sample is generated to determine the direction and probability of the incoming ray, and a new ray is generated with the intersection as the origin and the direction as the previously generated random sample. We decrease the depth so the recursive call knows when to stop. We check if it has any intersections, and if it does we run a recursive call on it. Finally, add the output to monte carlo, where L_in is the result of the recursive call, pdf is the pdf of the sample, and the additional detail that we divide by the survival rate to make sure the estimator is unbiased.

Part 5: Adaptive Sampling

Some samples converge very quickly while some samples require a lot of percision to get the correct value. We can solve this by defining a 95% confidence interval and accepting the input if the mean is 0.05% within I = 1.96 * std / sqrt(num), to do this i kept two variables s1 and s2 which stored the sum and the square of the sum to calculate the variables including I, std, and mean.
